显示端 UI 设计详细文档

ESP32 LoRa WildCam Open Kit Display Gateway UI

面向 ST7789V3 竖屏显示端，分辨率 240 × 320 像素。本文档定义页面结构、像素布局、字段、交互、状态与验收标准，可直接用于固件 UI 开发。

1. UI 目标与硬件约束

显示端是项目演示的核心窗口，第一目标是让项目组和客户立即看到“图片已回传，链路质量如何”。

屏幕

ST7789V3，240 × 320 像素，竖屏。建议使用 RGB565 色彩，刷新尽量采用局部刷新。

输入

主交互按物理侧键设计。若屏幕带触摸，可作为增强，但第一版不依赖触摸。

主任务

显示最新图片、接收进度、RSSI/SNR、传输速率、耗时、丢包率、电量和节点状态。

开发原则

字段少、对比强、刷新稳定。避免复杂动画和大量中文小字，优先保证户外可读性。

核心结论：240 × 320 屏幕不能做复杂 App，应设计成“仪表盘式 UI”：一屏看图，一屏看链路，一屏配置，一屏控制。

2. 页面信息架构

第一版建议实现 6 个页面，其中 P0 必须完成 4 个页面。

页面 用途 入口 优先级 关键字段
首页/最新图片页 显示最近一次回传图片和核心状态。 开机默认页、接收完成后自动跳转。 P0 图片、触发原因、时间、Node ID、远端电量、RSSI、速率。
接收进度页 图片传输过程中显示进度。 收到 IMAGE_START 自动进入。 P0 包进度、百分比、速率、RSSI/SNR、重传次数、耗时。
链路详情页 给演示和调试使用，展示无线链路指标。 侧键切换。 P0 RSSI、SNR、丢包率、重传率、吞吐、距离估算、FLRC 参数。
设备状态页 查看本机与拍摄端状态。 侧键切换。 P0 本机电量、远端电量、模式、固件版本、在线状态、最后心跳。
配置页 设置拍照周期、图片尺寸、触发方式等参数。 长按确认键或菜单入口。 P1 周期、尺寸、质量、触发源、音频开关、FLRC profile。
控制页 手动下发命令。 侧键切换或配置页进入。 P1 拍照、播放音频、休眠、刷新状态、开启 Wi-Fi AP。

3. 全局布局规范

所有页面使用同一套区域划分，降低开发复杂度和刷新风险。

区域 坐标 尺寸 内容 刷新规则
状态栏 x=0, y=0 240 × 22 Node ID、链路图标、本机电量、远端电量、时间/状态。 1s 刷新一次；接收中 500ms 刷新。
标题栏 x=0, y=22 240 × 28 页面标题和小状态标签。 切页或状态变化时刷新。
内容区 x=0, y=50 240 × 242 图片、列表、指标、配置项。 按页面局部刷新。
底部提示栏 x=0, y=292 240 × 28 侧键提示：返回/上/下/确认，或当前操作提示。 切页、选中项变化时刷新。

颜色规范

  • 屏幕背景：#EEF3EF
  • 容器面板：#FFFFFF
  • 状态栏：#263831
  • 主文字：#18231F
  • 选中/确认：#2F7D5B
  • 警告/接收：#B76A2C

字体规范

  • 状态栏：10px，高度 22px。
  • 标题：14px，加粗，高度 28px。
  • 正文字段：11px。
  • 关键数值：12px 或 14px。
  • 中文尽量不超过 8 字一行。

图标规范

  • 尽量使用 1-bit/2-bit 简单图标。
  • 电量、链路、接收、告警必须有图标。
  • 图标尺寸建议 10×10 或 12×12。
  • 错误状态用红色边框和文字，不依赖图标单独表达。

6. 物理按键与交互

按开发板实拍，显示端按键位于右侧面。UI 不在屏幕正面画虚拟按键，只在底部给侧键提示。

按键 短按 长按 1.5s 接收中行为 备注
K6 顶部侧键 返回上一层 / 返回首页 进入/退出菜单 取消当前接收 优先作为安全退出键。
K5 上一页 / 上一项 快速上翻 无动作 配置列表中向上移动。
K4 下一页 / 下一项 快速下翻 无动作 配置列表中向下移动。
K3 底部侧键 确认 / 执行当前操作 手动拍照 标记当前接收为重点事件 首页长按直接下发拍照命令。

触摸屏兼容：如果屏幕带触摸，点击列表行等同 K3，左右滑动等同 K5/K4 切页；但固件验收以侧键可完整操作为准。

7. 状态与错误显示

错误信息必须短、明确、可定位。显示端应尽量保留上一张成功图片，避免黑屏。

状态 触发条件 显示位置 显示内容 恢复规则
未配对 开机后未收到 Camera Node HELLO。 首页图片框 等待节点 N01 收到 HELLO 后自动进入首页。
正在接收 收到 IMAGE_START。 接收进度页 百分比、包数、速率。 完成后进入首页。
缺包重传 IMAGE_ACK 中存在缺包。 接收进度页 橙色显示 Retry 03。 重传完成后恢复绿色。
接收失败 超时、CRC 错误过多、用户取消。 标题栏 + 图片框下方 红色 RX FAIL E02。 保留上一张图片；10s 后错误提示降级为状态栏图标。
远端低电 Camera Node 电量低于 20%。 状态栏 C:18% 橙色闪烁。 电量恢复或更换电池后取消。
离线 超过心跳超时时间未收到 STATUS。 状态栏、设备状态页 OFFLINE 再次收到 HELLO/STATUS 后恢复。

8. 数据字段定义

UI 字段与通信协议字段保持一致，避免显示端二次推断。

UI 字段 来源包 类型 显示格式 备注
Node ID HELLO / STATUS / IMAGE_START uint16 N01 第一版默认单节点，也按 ID 显示。
触发原因 IMAGE_START / STATUS enum Timer / PIR / Sound / Manual / Cmd 首页标题栏标签。
图片大小 IMAGE_START uint32 128KB 按 1024 进位。
图片尺寸 IMAGE_START enum QVGA / VGA 首页和配置页显示。
RSSI 每包接收结果 int16 -72 dBm 显示最近 8 包平均值。
SNR 每包接收结果 float 8.5 dB 如当前模式无 SNR，则显示 LQ。
有效速率 本地计算 float 13.2 KB/s 图片大小 / 有效传输时间。
电量 STATUS uint8 C:76% C 为拍摄端，G 为显示端。
固件版本 HELLO / STATUS string v0.1.0 设备状态页显示。

9. 刷新与性能要求

ST7789V3 全屏刷新成本较高，建议尽量局部刷新。

刷新策略

  • 状态栏：1s 定时刷新。
  • 接收进度：每 4 包或 200ms 刷新一次，取更慢者。
  • 图片显示：接收完成后一次绘制。
  • 配置列表：只刷新旧选中行和新选中行。

图片绘制

  • 建议解码/缩放到 216×162 显示。
  • 图片区域背景先清黑，再绘制图像。
  • 图片边框固定，不随图片尺寸变化。
  • 失败时保留上一张成功图片。

内存约束

  • 避免全屏双缓冲。
  • 优先使用小块 line buffer。
  • UI 文本静态化，减少动态字符串分配。
  • 历史图片不在显示端 RAM 中长期缓存。

11. UI 验收标准

第一版验收以“可演示、可调试、可复现”为准。

P0 验收

  • 开机后进入首页，未连接时显示等待节点。
  • 收到 IMAGE_START 自动进入接收进度页。
  • 接收完成后自动回首页并显示图片。
  • 首页显示触发原因、图片大小、远端电量、RSSI、速率。
  • 链路详情页显示 RSSI/SNR、速率、丢包率、重传次数。
  • 侧键可完成切页、返回、手动拍照命令。
  • 接收失败时显示错误，但保留上一张成功图片。

P1 验收

  • 配置页可修改拍照周期、图片尺寸、质量、触发方式。
  • 可开启 Wi-Fi AP 配置入口。
  • 控制页可下发播放音频、休眠、刷新状态命令。
  • 设备状态页显示本机/远端电量、固件版本和最后心跳。
  • 触摸屏如接入，触摸操作与侧键操作一致。
