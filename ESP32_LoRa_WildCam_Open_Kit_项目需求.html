1. 项目定位

先把它定义清楚：这是一套“远距离无线野外图像节点”开源参考设计，不是消费级高清相机。

ESP32 LoRa WildCam Open Kit 是什么：一套由“野外相机端 + 手持接收端”组成的开源套件。野外相机端部署在树干、围栏、农场、林地或户外入口处，平时低功耗休眠；被定时、PIR/红外或声音触发后拍照，并通过 LR2021 FLRC 把图片回传到手持接收端。接收端显示图片、电量、距离、信号质量和传输速率，用来演示 ESP32+LR2021 模组在远距离图像传感器场景中的能力。

远距离 不依赖现场 Wi-Fi 覆盖，拍摄端通过 LR2021 把事件图片和状态发给接收端。
低功耗 拍摄端常态休眠，只有定时、PIR/红外、声音或命令触发时才唤醒工作。
可视化 接收端屏幕直接展示图片、RSSI/SNR、传输耗时、速率、丢包率和电量。
可复现 以 GitHub 开源项目交付固件、协议、外壳、BOM、接线图和测试数据。

野生动物观测

部署在林地、院子、鸟类活动点或动物路径附近。定时拍照或由 PIR 触发，接收端查看最新图片和触发时间，用于低成本记录“有什么动物出现过”。

农场/林业监测

部署在果园、农田、林区边界、饲料点或仓储入口。用于查看野生动物、牲畜、人员或异常活动，适合展示远距离图像节点和多点部署潜力。

户外安防告警

部署在围栏、临时工地、户外设备箱或偏远入口。触发后拍照回传，可选播放预设音频，作为低成本户外告警和事件确认方案。

模组能力 Demo

用于展会、客户拜访和代理商演示。现场按键触发拍照，接收端实时显示图片传输进度、速率和链路质量，让客户直观看到 LR2021 的价值。

项目最终交付

  • 两块开发板跑通拍摄端和接收端。
  • 完整开源固件、通信协议和接线说明。
  • 3D 打印外壳、BOM、测试报告和演示素材。

能力边界

  • 不做连续视频流。
  • 不承诺板端动物识别 AI。
  • 不依赖 SD 卡存储。

2. 既定硬件与设计边界

项目需求以当前已定型开发板为基础，避免提出必须改板才能实现的核心功能。

硬件条件 当前能力 需求影响 项目策略
主控与无线 ESP32 + LR2021 二合一模组，8M Flash + 8M PSRAM。 可完成拍照缓存、分片传输、近场 Wi-Fi 配置和低功耗控制。 把 LR2021 FLRC 图传和链路指标作为主卖点。
摄像头 低像素 SP0A39。 不适合高清图像和物种细节识别。 定位为事件确认、场景截图、低成本野外图像节点。
存储 无 SD 卡。 拍摄端无法长期本地保存图片/音频。 采用“即拍即传”，显示端/PC/Web 端保存。
音频 麦克风、扬声器可插接。 可做声音触发、拍照同步录音、动物声音模拟和安防告警。 音频列为 P1，先保证拍照和图传闭环。
显示 触摸 LCD 可插接。 适合做显示端/网关端 UI，不适合拍摄端常插屏。 拍摄端不插屏低功耗，显示端接屏做可视化演示。
供电 带电池插槽。 可做电池供电演示，但实际待机功耗受开发板 LDO、USB 芯片和外设影响。 区分开发板功耗与模组级潜力，提供实测数据。
结构 外壳可按需求设计 3D 打印件。 可形成完整开源项目资产。 提供拍摄端户外壳和显示端桌面/手持壳。

3. 系统架构

采用两块开发板组成完整链路：拍摄端负责低功耗采集，显示端负责接收、显示、配置和演示。

Camera Node 拍摄端

  • 不插 LCD，低功耗优先。
  • SP0A39 拍照，PSRAM 缓存。
  • 定时、红外/PIR、声音、手动命令触发。
  • 可插麦克风和扬声器。
  • 电池供电，定期上报电压。
  • 3D 打印户外外壳。

  • 下发拍照、播放音频、切换模式命令。

4. 工作模式

工作模式要服务开源演示和真实野外节点两类需求。

模式 触发方式 核心流程 主要展示价值 优先级
延时摄影模式 RTC 定时唤醒 按周期唤醒、拍照、发送、休眠。 展示低功耗周期采集，适合野外、农场、林业监测。 P0
红外/PIR 触发模式 外接 PIR 或红外触发模块 目标经过后唤醒，拍照并发送事件图片。 展示野外相机典型事件触发能力。 P0
声音触发模式 麦克风音量阈值或声音检测 声音超过阈值后唤醒，拍照并可同步录音。 展示鸟鸣、动物叫声、异常声音监测能力。 P1
手动演示模式 显示端触摸按钮或串口命令 下发拍照命令，实时显示传输进度和链路指标。 最适合展会、客户拜访和视频演示。 P0
安防/驱离模式 事件触发或远程命令 播放预设音频，记录告警事件，发送图片。 展示扬声器扩展和户外安防应用。 P1
多节点模式 多个拍摄端上报 显示端按 Node ID 接收不同节点图片和状态。 展示 LR2021 组网和 ToB 扩展潜力。 P2

5. 功能需求清单

优先保证开源项目第一版能跑通、能复现、能演示，再扩展高级功能。

模块 需求 验收标准 优先级
拍照 支持 SP0A39 初始化、QVGA/VGA 拍照、PSRAM 缓存、压缩质量配置。 拍摄端可稳定生成可显示图片，显示端可完整展示。 P0
延时摄影 支持 1 分钟、5 分钟、30 分钟、1 小时等周期配置。 拍摄端按配置周期唤醒、拍照、发送并回到休眠。 P0
红外/PIR 唤醒 支持 GPIO 外部唤醒，兼容常见 PIR/红外模块。 触发后 5 秒内完成拍照流程启动。 P0
FLRC 图传 图片分片发送，支持包序号、总包数、CRC、缺包重传。 在演示距离内，图片可重组，显示端展示传输耗时和平均速率。 P0
链路指标 显示 RSSI、SNR 或等效链路质量、包数、丢包率、重传次数、速率。 每次图传完成后显示端自动刷新指标。 P0
低功耗 拍摄端常态 deep sleep，事件完成后自动休眠。 提供实测待机电流、拍照电流、发送电流、一次事件能耗。 P0
近场 Wi-Fi 配置 通过 Wi-Fi AP 页面配置模式、周期、图片尺寸、触发源、音频开关。 手机连接 AP 后可修改配置，重启后配置保持。 P0
电量显示 拍摄端上报电池电压和估算电量，显示端显示本机与远端电量。 显示端图片页或状态页能看到两个设备电量。 P0
声音触发 麦克风检测音量阈值，超过阈值触发拍照。 阈值可配置，触发事件中记录 trigger=sound。 P1
同步录音 拍照时同步采集 3-10 秒低码率音频，可选择传输或仅保存摘要。 显示端可看到音频状态；如传输音频，可在 PC/Web 端导出。 P1
音频播放 支持播放预设音频，用于动物声音模拟或安防告警。 显示端可下发播放命令，拍摄端执行并回传结果。 P1
手动控制 显示端支持手动拍照、切换模式、播放音频、休眠命令。 触摸屏或串口命令可成功控制拍摄端。 P1
多节点 一个显示端接收多个 Camera Node。 显示端按 Node ID 展示最新图片和状态。 P2
Web 导出 显示端提供 Web 页面或 USB 工具导出图片、日志和链路数据。 电脑/手机可查看历史事件与下载图片。 P2

6. 通信协议需求

协议要简单、公开、可复用，帮助客户理解 LR2021 模组能做什么。

数据包类型

  • HELLO：节点上线与配对。
  • STATUS：电量、模式、固件版本、唤醒原因。
  • IMAGE_START：图片 ID、大小、分辨率、总包数。
  • IMAGE_CHUNK：图片分片数据。
  • IMAGE_ACK：接收确认和缺包列表。
  • CMD：拍照、休眠、播放音频、切换模式。
  • AUDIO_META：音频片段元数据。

关键指标

  • 图片大小：Bytes。
  • 总包数、成功包数、重传包数。
  • 首包时间、尾包时间、总耗时。
  • 平均有效速率：图片大小 / 传输耗时。
  • RSSI、SNR 或 LR2021 可提供的链路质量指标。
  • 触发原因：timer / pir / sound / manual / command。
Packet Header v1
--------------------------------------------------
magic        2 bytes   固定标识
version      1 byte    协议版本
type         1 byte    数据包类型
node_id      2 bytes   拍摄端 ID
session_id   2 bytes   会话 ID
seq          2 bytes   当前包序号
total        2 bytes   总包数
payload_len  2 bytes   负载长度
crc16        2 bytes   头部+负载校验
payload      N bytes   图片分片/状态/命令

7. 显示端 UI 需求

显示端是开源项目最重要的演示窗口，需要让客户一眼看到“图片传过来了，链路质量如何”。

图片页

显示最新图片、拍摄时间、触发原因、远端电量、Node ID。

链路页

显示 RSSI/SNR、传输速率、耗时、丢包率、重传次数、包进度。

配置页

配置拍照周期、图片尺寸、触发方式、FLRC 参数、音频开关。

控制页

手动拍照、播放音频、进入休眠、刷新状态、切换工作模式。

12. 风险与取舍

这些风险需要在 README 和产品介绍中主动说明，避免用户预期偏差。

风险 影响 处理策略
摄像头像素低 图片无法与商业野外相机对比，动物细节有限。 明确定位为低成本事件确认和 LR2021 图传 Demo。
无 SD 卡 拍摄端无法保存大量历史图片。 采用即拍即传；显示端或 PC 端保存图片。
